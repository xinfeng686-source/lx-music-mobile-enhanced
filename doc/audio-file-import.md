# 本地音频多选导入

入口：歌单菜单 → 添加本地歌曲 → 顶部“选音频”。

点击文件勾选，再次点击取消；可以进入不同文件夹继续选择。底部“导入（数量）”汇总所有文件夹的选择，点击后确认数量和目标歌单。重新打开浏览器会清空选择。“选文件夹”切回原有文件夹扫描。新建文件夹、刷新、存储切换保留。

文件筛选包含 MP3、FLAC、M4A、M4B、AAC、WAV、OGG、OPUS、APE、WMA、AIFF、DSF 等 31 种扩展名，忽略大小写。扩展名可见不等于保证可解码；元数据读取与播放沿用原有组件。读取失败单独计数，重复路径及歌单已有文件跳过；不复制、不修改原始音频文件。

界面复用原有主题颜色、按钮、弹窗和文件浏览器布局，提供简体中文、繁体中文及英文文案。
